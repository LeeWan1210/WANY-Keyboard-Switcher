### Windows용 실행 파일

**[WANY Keyboard Switcher v0.4 다운로드](https://github.com/LeeWan1210/WANY-Keyboard-Switcher/releases/download/v0.4/WANY-Keyboard-Switcher-v0.4.exe)** · [소스코드 ZIP](https://github.com/LeeWan1210/WANY-Keyboard-Switcher/releases/download/v0.4/WANY-Keyboard-Switcher-v0.4-source.zip)

Windows 10/11 64비트에서 일본어(JIS) 및 미국식(US) 키보드 배열을 수동으로 전환하는 프로그램입니다. AutoHotkey 또는 별도의 Interception 드라이버를 설치할 필요가 없습니다.

### v0.4 변경 사항

- 실행 파일 자체와 알림 영역에 키보드 그림 아이콘을 추가했습니다. US는 파란색, JIS는 주황색으로 구분됩니다.
- **키 변환 일시중지/다시 시작 기능을 추가했습니다.** 프로그램을 종료하지 않고 키 변환을 끄면 원래 키 입력을 그대로 통과시키며, 알림 영역 아이콘이 일시중지 표시가 있는 회색 키보드로 바뀝니다. 설정은 재실행 후에도 유지됩니다.
- 프로그램 메뉴를 한국어·영어·일본어로 전환할 수 있고, 선택한 언어가 저장됩니다.
- 이전 v0.2의 기본 키 입력 보정 로직을 유지합니다.

### 사용 방법

1. 이전 버전이 실행 중이라면 먼저 종료합니다.
2. EXE를 실행한 뒤 화면 오른쪽 아래 알림 영역의 키보드 아이콘을 찾습니다.
3. **왼쪽 클릭:** 사용 중에는 US/JIS 전환, 일시중지 중에는 다시 시작. **오른쪽 클릭:** 배열 직접 선택, **키 변환 일시중지/다시 시작**, 일본어 입력기의 Windows 기준 배열, 메뉴 언어, 진단 로그, 종료.
4. 일본어 물리 키보드라면 **JIS**, 미국식 물리 키보드라면 **US**를 선택합니다. 일본어 입력기 기준 배열은 Windows에 실제 설정된 배열과 일치시켜야 합니다.

**알려진 제한:** 전체 키보드 배열을 교체하는 도구가 아니라 일부 기호 키를 보정하는 시험판입니다. 일본어 변환 중 입력, `¥`, `ろ`, 일본어 전용키 및 관리자 권한 앱 등에서는 별도 검증이 필요합니다. 이상 동작 시 알림 영역 메뉴나 작업 관리자에서 종료하세요.

### Windows executable

**[Download WANY Keyboard Switcher v0.4](https://github.com/LeeWan1210/WANY-Keyboard-Switcher/releases/download/v0.4/WANY-Keyboard-Switcher-v0.4.exe)** · [Source ZIP](https://github.com/LeeWan1210/WANY-Keyboard-Switcher/releases/download/v0.4/WANY-Keyboard-Switcher-v0.4-source.zip)

A Windows 10/11 64-bit tool to manually switch between Japanese (JIS) and US physical-keyboard profiles. It does not require AutoHotkey or an Interception driver.

### What's new in v0.4

- Illustrated keyboard icons for the executable and notification area; blue for US and orange for JIS.
- **Pause/resume key conversion without closing the application.** When paused, original key input passes through unchanged and the notification-area icon becomes a gray keyboard with a pause badge. The state persists after restarting.
- Korean, English, and Japanese menu languages with persistent selection.
- Preserves the symbol-key correction behavior introduced in v0.2.

### Getting started

1. Exit earlier versions before launching v0.4.
2. Run the EXE and find its keyboard icon in the Windows notification area.
3. **Left-click:** toggle US/JIS while active or resume when paused. **Right-click:** select a layout, **pause/resume conversion**, set the Japanese IME baseline, change menu language, configure diagnostics, or exit.
4. Select **JIS** for a physical Japanese keyboard or **US** for a physical US keyboard. Match the Japanese IME baseline to the actual hardware layout configured in Windows.

**Known limitations:** This experimental utility adjusts only some symbol keys; it does not replace the system-wide keyboard layout. Japanese IME composition, `¥`, `ろ`, Japanese-specific keys, and elevated applications require further testing. If input behaves unexpectedly, exit via the notification-area menu or Task Manager.

### Windows 用実行ファイル

**[WANY Keyboard Switcher v0.4 をダウンロード](https://github.com/LeeWan1210/WANY-Keyboard-Switcher/releases/download/v0.4/WANY-Keyboard-Switcher-v0.4.exe)** · [ソースコード ZIP](https://github.com/LeeWan1210/WANY-Keyboard-Switcher/releases/download/v0.4/WANY-Keyboard-Switcher-v0.4-source.zip)

Windows 10/11 の 64 ビット環境で、日本語（JIS）配列と US 配列のプロファイルを手動で切り替えるツールです。AutoHotkey や Interception ドライバーの導入は不要です。

### v0.4 の変更点

- 実行ファイルと通知領域にキーボードのイラストアイコンを追加しました。US は青、JIS はオレンジ色です。
- **アプリを終了せずにキー変換を一時停止／再開できる機能を追加しました。** 停止中は元のキー入力をそのまま通し、通知領域のアイコンが一時停止マーク付きの灰色のキーボードに変わります。この状態は次回起動時にも保持されます。
- メニューの表示言語を韓国語・英語・日本語から選択でき、設定を保存します。
- v0.2 の記号キー補正動作を維持しています。

### 使い方

1. 旧バージョンが動作している場合は、先に終了してください。
2. EXE を起動し、画面右下の通知領域にあるキーボードアイコンを探します。
3. **左クリック：** 通常時は US/JIS の切り替え、一時停止中は変換を再開。**右クリック：** プロファイル選択、**キー変換の一時停止／再開**、日本語 IME の Windows 側基準配列、表示言語、診断ログ、終了。
4. 日本語配列の物理キーボードでは **JIS**、US 配列では **US** を選択します。日本語 IME の基準配列を Windows で実際に設定している配列と一致させてください。

**既知の制限：** Windows 全体の配列を置き換えるのではなく、一部の記号キーを補正する試験版です。日本語 IME の変換中の入力、`¥`、`ろ`、日本語固有キー、管理者権限で動作するアプリなどは追加検証が必要です。入力がおかしい場合は、通知領域のメニューまたはタスクマネージャーから終了してください。
