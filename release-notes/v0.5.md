### 다운로드

Windows 10/11 64비트용 프로그램입니다. 실행 파일과 소스 ZIP의 이름에는 버전 번호를 넣지 않았으며, 릴리즈 태그에서 버전을 관리합니다.

### v0.5 변경 사항

- 입력 진단 로그 및 관련 메뉴를 제거했습니다.
- 프로그램 실행 시 GitHub의 최신 정식 릴리즈를 확인합니다. 업데이트가 있다면 **먼저 설치 여부를 묻고**, 동의한 경우에만 EXE를 다운로드합니다.
- 다운로드한 EXE는 GitHub가 게시한 SHA-256 해시와 파일 크기로 검증합니다. 검증 후 기존 프로그램을 종료하고 파일을 교체한 다음 자동 재실행합니다.
- 오른쪽 클릭 메뉴의 **「업데이트 확인」**에서 수동 확인도 가능합니다.
- 이전 버전의 US/JIS 전환, 일시중지 및 회색 아이콘, 한국어·영어·일본어 메뉴 기능을 유지합니다.

### 설치 및 사용

1. v0.4 및 이전 버전이 실행 중이라면 종료한 뒤, 이 릴리즈에서 새 EXE를 **한 번 직접 다운로드하여** 실행합니다. 이전 버전에는 자동 업데이트 기능이 없습니다.
2. 일시중지 상태에서도 업데이트를 확인할 수 있습니다. 새 버전이 발견되면 승인 여부를 선택하세요. **거절하면 다운로드·교체·재실행하지 않습니다.**
3. 동의 후 프로그램 폴더에 쓰기 권한이 없거나 파일 교체에 실패하면 자동 업데이트가 완료되지 않을 수 있습니다. 필요한 경우 새 EXE를 직접 다운로드해 교체해 주세요.

**알려진 제한:** 이 프로그램은 전체 키보드 배열을 교체하지 않으며, 일부 특수문자 키를 보정하는 시험판입니다. 일본어 IME 변환 중의 입력과 일본어 전용키는 환경별 검증이 더 필요합니다. 자동 업데이트의 실제 Windows 동작 역시 추가 사용 테스트가 필요합니다.

### Download

**[Download Windows EXE](https://github.com/LeeWan1210/WANY-Keyboard-Switcher/releases/download/v0.5/WANY-Keyboard-Switcher.exe)** · [Download source ZIP](https://github.com/LeeWan1210/WANY-Keyboard-Switcher/releases/download/v0.5/WANY-Keyboard-Switcher-source.zip)

For Windows 10/11, 64-bit. The executable and source archive now have version-free filenames; release tags identify versions.

### What's new in v0.5

- Removed input diagnostic logging and its tray-menu option.
- Automatically checks the latest stable GitHub Release at startup. **It asks for approval before downloading or installing anything.**
- After approval, verifies the downloaded executable against the SHA-256 digest and size published by GitHub, closes the running app, replaces the EXE, and restarts.
- Added **Check for updates** to the right-click menu.
- Preserves the US/JIS toggle, pause/resume with gray icon, and Korean/English/Japanese menu languages.

### Installation and use

1. Exit v0.4 or earlier and **download the new EXE manually once**; those versions do not have the updater.
2. Update checks work while key conversion is paused. Declining an update leaves the current program and executable unchanged.
3. If you cannot write to the program folder, automatic replacement may fail. You can download and replace the EXE manually.

**Limitations:** This is an experimental correction of selected symbol keys, not a full Windows keyboard layout replacement. Japanese IME composition and Japanese-specific keys need device-specific testing. The updater's complete Windows install/restart flow also needs testing on a real Windows machine.

Windows 10/11 の 64 ビット版に対応しています。実行ファイルおよびソース ZIP のファイル名からバージョン番号を除き、リリースタグでバージョンを管理します。

### v0.5 の変更点

- 入力診断ログと関連するメニュー項目を削除しました。
- 起動時に GitHub の最新の正式リリースを確認します。更新がある場合は**ダウンロード前に必ずユーザーへ確認**します。
- 同意後、GitHub が公開する SHA-256 ハッシュとファイルサイズで EXE を検証し、旧アプリを終了して実行ファイルを置き換え、再起動します。
- 右クリックメニューに **「更新を確認」** を追加しました。
- US/JIS 切り替え、灰色アイコンによる一時停止／再開、韓国語・英語・日本語のメニューを維持しています。

### 導入と使い方

1. v0.4 以前を終了し、このリリースの EXE を**最初の一回だけ手動でダウンロード**してください。旧バージョンには自動更新機能がありません。
2. キー変換の一時停止中も更新確認が可能です。更新を拒否した場合、ダウンロード・置換・再起動は行いません。
3. アプリを置いたフォルダーに書き込み権限がない場合、更新に失敗する可能性があります。その場合は EXE を手動で置き換えてください。

**既知の制限：** 一部の記号キーを補正する試験版であり、Windows 全体の配列は置き換えません。日本語 IME の変換中の入力や日本語固有キーは環境別の検証が必要です。自動更新と再起動の一連の動作も Windows 実機での追加確認が必要です。

[日本語の詳しい使い方](https://github.com/LeeWan1210/WANY-Keyboard-Switcher/blob/main/README.ja.md)
