### 변경 사항

- 알림 영역 아이콘의 오른쪽 클릭 메뉴에 **Windows 시작 시 자동 실행** 옵션을 추가했습니다.
- 옵션을 켜면 현재 실행 중인 EXE 경로를 현재 사용자 계정의 Windows 시작프로그램에 등록합니다.
- 등록은 `HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run`을 사용하므로 관리자 권한이 필요하지 않습니다.
- 메뉴의 체크 상태는 별도 설정값이 아니라 실제 Windows 시작프로그램 등록 상태를 기준으로 표시합니다.
- EXE를 다른 폴더로 옮긴 경우 새 위치에서 다시 옵션을 켜면 현재 경로로 등록됩니다.
- 한국어·영어·일본어 메뉴와 오류 메시지를 지원합니다.
- 기존 US/JIS 전환, 일시중지/다시 시작, 다국어 표시, 사용자 동의 기반 GitHub 자동 업데이트 기능은 그대로 유지했습니다.

### 사용 방법

작업표시줄 알림 영역의 WANY Keyboard Switcher 아이콘을 오른쪽 클릭한 뒤 **Windows 시작 시 자동 실행**을 선택하세요. 체크 표시가 있으면 현재 EXE가 다음 Windows 로그인부터 자동 실행되도록 현재 사용자 계정에 등록된 상태입니다.

이 기능은 모든 사용자용 서비스나 작업 스케줄러를 만들지 않으며 관리자 권한도 요구하지 않습니다.

**검증:** Go 테스트와 Windows amd64 전체 크로스빌드를 통과한 소스를 릴리즈합니다. 실제 Windows 로그인 후 자동 실행 동작은 사용자 환경에서 추가 확인이 필요할 수 있습니다.

### Download

### Changes

- Added **Run at Windows startup** to the notification-area right-click menu.
- Enabling it registers the currently running EXE path for the current Windows user.
- Registration uses `HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run`, so administrator rights are not required.
- The menu check state reflects the actual Windows startup registration instead of a duplicated app setting.
- If the EXE is moved, enabling the option again from the new location registers the current path.
- Korean, English, and Japanese menu text and error messages are supported.
- Existing US/JIS switching, pause/resume, multilingual display, and consent-first GitHub updates remain unchanged.

### Use

Right-click the WANY Keyboard Switcher notification-area icon and choose **Run at Windows startup**. A check mark means the current EXE is registered to launch for the current user at the next Windows sign-in.

This feature does not create an all-users service or scheduled task and does not require administrator rights.

**Verification:** The release source has passed Go tests and the complete Windows amd64 cross-build. Actual post-login startup behavior may still require confirmation on individual Windows environments.

### ダウンロード

**[Windows 用 EXE](https://github.com/LeeWan1210/WANY-Keyboard-Switcher/releases/download/v0.7/WANY-Keyboard-Switcher.exe)** · [ソースコード ZIP](https://github.com/LeeWan1210/WANY-Keyboard-Switcher/releases/download/v0.7/WANY-Keyboard-Switcher-source.zip)

### 変更点

- 通知領域アイコンの右クリックメニューに **Windows 起動時に自動実行** を追加しました。
- 有効にすると、現在実行している EXE のパスを現在の Windows ユーザーの自動起動に登録します。
- `HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run` を使用するため、管理者権限は不要です。
- メニューのチェック状態は、アプリ内の重複設定ではなく実際の Windows 自動起動登録状態を反映します。
- EXE を別のフォルダーへ移動した場合も、新しい場所で再度有効にすると現在のパスを登録できます。
- 韓国語・英語・日本語のメニュー表示とエラーメッセージに対応しています。
- 既存の US/JIS 切り替え、一時停止／再開、多言語表示、ユーザー同意を必要とする GitHub 更新機能は維持しています。

### 使い方

通知領域の WANY Keyboard Switcher アイコンを右クリックし、**Windows 起動時に自動実行** を選択してください。チェックが付いている場合、現在の EXE が次回の Windows サインイン時から現在のユーザーで自動実行されるよう登録されています。

この機能は全ユーザー向けサービスやタスクスケジューラを作成せず、管理者権限も必要ありません。

**検証:** リリースするソースは Go テストと Windows amd64 全体のクロスビルドに成功しています。実際の Windows サインイン後の自動起動は、個々の環境で追加確認が必要な場合があります。
