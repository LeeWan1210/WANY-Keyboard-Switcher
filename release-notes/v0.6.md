### 변경 사항

- 언어 변경을 오른쪽 클릭 메뉴의 **「표시 언어」 하위 메뉴**로 옮겼습니다. 하위 메뉴에서 한국어·영어·일본어를 선택할 수 있습니다.
- 일시중지 메뉴의 로마 숫자처럼 보이던 `Ⅱ` 표시를 **⏸ 일시중지**로 교체했습니다.
- 일시중지 중 알림 영역 아이콘을 회색 키보드에 **원형 일시중지 배지**가 붙은 형태로 변경했습니다. 다시 시작하면 기존 US/JIS 아이콘이 복구됩니다.
- 기존 키 변환, 프로그램을 종료하지 않는 일시중지, 사용자 승인 후 GitHub 자동 업데이트 기능은 유지했습니다.

### 사용 방법

작업표시줄 알림 영역에서 아이콘을 오른쪽 클릭하여 **표시 언어 → 한국어 / English / 日本語**를 선택하세요. 변환을 잠시 끄려면 **⏸ 키 변환 일시중지**를 누릅니다. 회색 아이콘을 왼쪽 클릭하거나 오른쪽 클릭 메뉴에서 다시 시작할 수 있습니다.

v0.5를 사용 중이라면 프로그램에서 새 버전 알림을 확인하고 업데이트에 동의하면 됩니다. 설치 여부를 거절하면 기존 프로그램이 그대로 유지됩니다. EXE 파일 이름은 이전 버전과 같이 `WANY-Keyboard-Switcher.exe`입니다.

**참고:** Windows 실기기에서 하위 메뉴 표시와 아이콘의 가독성은 추가 확인이 필요합니다.

### Download

**[Download Windows EXE](https://github.com/LeeWan1210/WANY-Keyboard-Switcher/releases/download/v0.6/WANY-Keyboard-Switcher.exe)** · [Source ZIP](https://github.com/LeeWan1210/WANY-Keyboard-Switcher/releases/download/v0.6/WANY-Keyboard-Switcher-source.zip)

### Changes

- Moved language selection into a **Display language** submenu in the notification-area right-click menu, with Korean, English, and Japanese choices.
- Replaced the Roman-numeral-like `Ⅱ` menu symbol with a recognizable **⏸ Pause** symbol.
- Updated the paused notification-area icon to show a **circular pause badge** on a gray keyboard. Resuming restores the US/JIS icon.
- Preserved existing key correction, pause without exiting, and consent-first GitHub Release updates.

### Use

Right-click the notification-area icon and choose **Display language → 한국어 / English / 日本語**. Choose **⏸ Pause key conversion** to disable correction temporarily. Left-click the gray icon or use the right-click menu to resume.

If you are running v0.5, you can approve the new version in its update prompt. Declining leaves the existing program unchanged. The executable filename remains `WANY-Keyboard-Switcher.exe`.

**Note:** Submenu rendering and icon legibility still need testing on a real Windows desktop.

### 変更点

- 通知領域の右クリックメニューに **「表示言語」サブメニュー**を設け、韓国語・英語・日本語の切り替え項目をまとめました。
- ローマ数字のように見えていた `Ⅱ` を、わかりやすい **⏸ 一時停止** の表示に変更しました。
- 一時停止中の通知領域アイコンを、灰色のキーボードに**丸い一時停止バッジ**を重ねたデザインに変更しました。再開すると US/JIS アイコンに戻ります。
- キーの補正、アプリを終了しない一時停止、ユーザーの同意を必要とする GitHub 更新機能は維持しています。

### 使い方

通知領域のアイコンを右クリックし、**表示言語 → 한국어 / English / 日本語**を選択してください。キー変換を一時停止するには **⏸ キー変換を一時停止**を選びます。灰色のアイコンを左クリックするか、右クリックメニューから再開できます。

v0.5 を使用している場合は、更新通知が表示されたら承認して更新できます。拒否すると現在のプログラムはそのまま維持されます。実行ファイル名は引き続き `WANY-Keyboard-Switcher.exe` です。

**注記：** サブメニューの表示とアイコンの見やすさは、Windows 実機での追加確認が必要です。
