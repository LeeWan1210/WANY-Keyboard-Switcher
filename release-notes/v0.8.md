### 변경 사항

- **중복 실행 방지**를 추가했습니다.
- 같은 Windows 세션에서 WANY Keyboard Switcher v0.8 이상이 이미 실행 중이면 두 번째 일반 실행은 즉시 종료됩니다.
- 따라서 실수로 EXE를 다시 실행하거나 Windows 시작프로그램과 수동 실행이 겹쳐도 두 번째 트레이 아이콘과 키보드 후킹이 생기지 않습니다.
- Windows named mutex를 사용하며, 프로그램이 정상 종료되거나 비정상 종료되면 Windows가 해당 프로세스의 mutex 핸들을 정리합니다.
- 자동 업데이트의 `--apply-update` 보조 프로세스는 기존 업데이트 흐름이 동작하도록 중복 실행 검사에서 제외했습니다.
- v0.7 이하 구버전 EXE에는 이 기능이 없으므로, 구버전을 별도로 실행 중이라면 먼저 종료하는 것을 권장합니다.
- v0.7의 **Windows 시작 시 자동 실행**, US/JIS 전환, 일시중지/다시 시작, 다국어 표시, 사용자 동의 기반 GitHub 자동 업데이트 기능은 그대로 유지했습니다.

### 사용 방법

별도의 설정은 필요하지 않습니다. v0.8을 실행한 상태에서 EXE를 다시 실행하면 두 번째 본체는 트레이 아이콘이나 키보드 후킹을 만들지 않고 종료됩니다.

**검증:** 관련 Go 테스트와 Windows amd64 전체 애플리케이션 크로스빌드를 통과한 소스를 릴리즈합니다. 실제 Windows 데스크톱에서의 반복 실행 동작은 환경별 추가 확인이 필요할 수 있습니다.

### Download

**[Download Windows EXE](https://github.com/LeeWan1210/WANY-Keyboard-Switcher/releases/download/v0.8/WANY-Keyboard-Switcher.exe)** · [Source ZIP](https://github.com/LeeWan1210/WANY-Keyboard-Switcher/releases/download/v0.8/WANY-Keyboard-Switcher-source.zip)

### Changes

- Added **duplicate-launch protection**.
- If WANY Keyboard Switcher v0.8 or later is already running in the same Windows session, a second normal launch exits immediately.
- This prevents an accidental second EXE launch, or overlapping Windows-startup and manual launches, from creating another tray icon or keyboard hook.
- The app uses a Windows named mutex. Windows releases the process handle when the app exits normally or crashes.
- The `--apply-update` self-update helper is intentionally exempt so the existing update flow can continue to work.
- v0.7 and earlier EXEs do not contain this protection, so exit a separately running older copy first.
- v0.7 features such as **Run at Windows startup**, US/JIS switching, pause/resume, multilingual UI, and consent-first GitHub updates remain unchanged.

### Use

No additional setting is required. With v0.8 already running, launching the EXE again causes the second normal app process to exit before it creates a tray icon or keyboard hook.

**Verification:** The release source has passed the relevant Go tests and the complete Windows amd64 application cross-build. Repeated-launch behavior on a real Windows desktop may still need environment-specific confirmation.

### ダウンロード

**[Windows 用 EXE](https://github.com/LeeWan1210/WANY-Keyboard-Switcher/releases/download/v0.8/WANY-Keyboard-Switcher.exe)** · [ソースコード ZIP](https://github.com/LeeWan1210/WANY-Keyboard-Switcher/releases/download/v0.8/WANY-Keyboard-Switcher-source.zip)

### 変更点

- **二重起動防止**を追加しました。
- 同じ Windows セッションで WANY Keyboard Switcher v0.8 以降がすでに起動している場合、2 回目の通常起動はすぐ終了します。
- EXE の誤った再実行や Windows 自動起動と手動起動が重なっても、2 個目の通知領域アイコンやキーボードフックは作成されません。
- Windows の named mutex を使用し、アプリの正常終了・異常終了時には Windows がプロセスのハンドルを解放します。
- 既存の更新フローを維持するため、`--apply-update` の自動更新補助プロセスは二重起動チェックから除外しています。
- v0.7 以前の旧 EXE にはこの機能がないため、別途実行中の旧バージョンは先に終了してください。
- v0.7 の **Windows 起動時に自動実行**、US/JIS 切り替え、一時停止／再開、多言語表示、同意を必要とする GitHub 更新機能は維持しています。

### 使い方

追加設定は不要です。v0.8 が起動中の状態で EXE を再度実行すると、2 回目の通常プロセスは通知領域アイコンやキーボードフックを作成する前に終了します。

**検証:** リリースするソースは関連する Go テストと Windows amd64 アプリ全体のクロスビルドに成功しています。実際の Windows デスクトップでの繰り返し起動は、環境ごとの追加確認が必要な場合があります。
